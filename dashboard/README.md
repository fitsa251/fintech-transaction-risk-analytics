# Excel Dashboard

This folder contains the Excel dashboard for the FinTech Customer Transaction & Risk Analytics project.

The dashboard summarizes:
- Total transactions
- Total transaction volume
- Total fee revenue
- Failure rate
- High-risk transactions
- Monthly transaction and revenue trends
- Payment channel performance
- Merchant category performance
- Customer segment performance
- Risk flag summary
- Failed transaction reasons
