# SQL Analysis

This folder contains SQL queries for the FinTech Customer Transaction & Risk Analytics project.

The SQL queries focus on:
- Executive KPI reporting
- Monthly transaction and revenue trends
- Payment channel performance
- Payment method performance
- Merchant category analysis
- Customer segment analysis
- Failed transaction analysis
- Risk flag review
- High-risk transaction monitoring
- Customer-level activity analysis
- State-level performance review
- Business performance by segment and channel

These queries are designed to support business analytics, financial operations, payment operations, FinTech reporting, and risk monitoring.
